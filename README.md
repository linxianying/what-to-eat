# 今天吃什么 · 大转盘 / 抽签器

一个零依赖、纯静态的「今天吃什么」决策小游戏，双击 `index.html` 即可离线运行，也可直接部署到 GitHub Pages。

## 功能特性

- **双模式切换**：
  - **大转盘**：SVG 动态分片 + CSS 缓动旋转动画，指针精准落点。
  - **抽签器**：摇签筒 CSS 动画 + 弹出趣味美食签。
- **自定义选项列表**：支持单个或逗号/空格批量添加、删除、打乱顺序、清空，并自动通过 `localStorage` 本地保存。
- **内置预设**：一键切换「工作餐 / 朋友聚餐 / 夜宵解馋 / 下午茶」。
- **实用细节**：支持「排除再抽」、最近抽取记录、Web Audio 轻量音效开关、浅色/深色主题切换，以及 `Space` 空格键快速开始。

## 本地使用

直接用浏览器打开 `index.html` 即可开始使用，无需安装任何依赖或构建工具。

## 部署到 GitHub Pages

在仓库的 **Settings → Pages** 中将 Source 设置为 `Deploy from a branch`，选择 `main` 分支根目录保存即可获得在线访问链接。
